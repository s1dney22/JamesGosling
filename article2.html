Список терминов

Java
Java — объектно-ориентированный язык программирования общего назначения. Изначально назывался Oak («Дуб») в честь дерева за окном офиса Гослинга, но позже был переименован в честь сорта кофе Java.
JVM
JVM (Java Virtual Machine) — виртуальная машина Java, которую Гослинг спроектировал для выполнения скомпилированного байт-кода на любой аппаратной платформе.
Bytecode
Байт-код (Bytecode) — промежуточный машинно-независимый код, в который компилируются исходные файлы Java.
Garbage Collection
Garbage Collection (Сборка мусора) — автоматическое управление памятью. Гослинг внедрил встроенный сборщик фонового мусора, чтобы избавить разработчиков от ручного удаления объектов (как в C++), приводящего к утечкам памяти.
WORA
WORA (Write Once, Run Anywhere) — концепция «Напиши один раз, запускай везде», описывающая кросс-платформенность Java, ставшую революционной благодаря JVM.
